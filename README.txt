MOHAMMED SHAMNAD & FATHIMA NIDHA — WEDDING INVITATION

This is a static, mobile-friendly wedding invitation website.

Preview locally: open index.html in a browser.
Deploy: upload this folder to a static hosting provider (for example, Vercel) or import it into a Git repository and deploy the folder as a static site.

Included: opening screen, family invitation, wedding date, live countdown, venue photo, Google Maps search directions, closing dua.

Note: The RSVP form and music are not connected. To enable RSVP, provide a WhatsApp number or an email address / preferred RSVP service. Confirm the exact venue map pin before sharing widely.
